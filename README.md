# 🏠 House Price Analysis – Data Science Mini Project

## 📌 Project Overview

This project performs exploratory data analysis (EDA) on a House Price dataset to understand the factors related to house prices.

The analysis uses Python, Pandas, Matplotlib, and Seaborn to explore the dataset and generate meaningful insights through data visualization.

## 🎯 Objectives

* Analyze the House Price dataset
* Understand the structure and characteristics of the data
* Check missing values and duplicate records
* Analyze relationships between house features and price
* Create meaningful visualizations
* Identify important patterns and correlations

## 🛠️ Technologies Used

* Python
* Google Colab
* Pandas
* Matplotlib
* Seaborn
* NumPy

## 📊 Dataset Features

The dataset contains information such as:

* Beds
* Baths
* House Size
* Zip Code
* Price

## 📈 Analysis Performed

The project includes:

* Dataset information
* Statistical analysis
* Missing value analysis
* Duplicate value checking
* Price distribution
* House Size vs Price analysis
* Bedrooms vs Price analysis
* Bathrooms vs Price analysis
* Correlation analysis
* Correlation heatmap
* Top expensive and cheapest houses

## 🔍 Key Insights

* House size has a relationship with house price.
* Larger houses generally tend to have higher prices.
* Bedroom and bathroom counts can be compared with house prices.
* Correlation analysis helps identify relationships between numerical features.
* Visualizations make the patterns in the dataset easier to understand.

## 📁 Project Files

* `House_Price_Analysis.ipynb` – Data analysis notebook
* `final_dataset.csv` – Dataset used for analysis
